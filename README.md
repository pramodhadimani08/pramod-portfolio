# Pramod Portfolio

Animated React + Vite portfolio.

## IMPORTANT: Run with Vite
Do NOT double-click `index.html`. React modules require the Vite development server.

Open a terminal in this folder and run:

```bash
npm install
npm run dev
```

Then open the `Local` URL printed by Vite, usually:
`http://localhost:5173/`

## Production build
```bash
npm run build
npm run preview
```

Replace the `#` placeholder links in `src/App.jsx` with actual LinkedIn, GitHub, project demo and certificate URLs.
